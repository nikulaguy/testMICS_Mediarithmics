# CountBadge

<DocMeta>

Pastille de comptage : hauteur `size/badge`, `radius/card`, chiffre en `text/on-dark`. Elle se pose **dans le flux**,
à côté d'un libellé, et non en exposant sur une icône. **Une exception, alignée sur la maquette** :
sur le déclencheur « Filter » du panneau de filtres, elle déborde du coin haut-droit du bouton
(top −7 / right −10, `pointer-events: none`, `aria-hidden` — le compte passe dans le nom accessible
du bouton). La couleur porte le sens : `info` pour un état neutre (nombre de filtres actifs),
`warning` pour des éléments à traiter, `success` pour « rien à traiter ».

## Règles d'usage

- **Jamais la pastille seule.** Elle accompagne toujours un libellé lisible : le nombre sans son
  objet ne veut rien dire, et un lecteur d'écran annoncerait « 3 » sans contexte.
- Le ton est **sémantique**. Un compteur d'alertes non traitées est `warning`, pas `info` parce
  que le bleu s'accorde mieux avec la barre.
- La pastille disparaît quand le compte vaut zéro, sauf si l'absence est l'information (`success`
  sur un tableau de bord de conformité).
- `flex: 0 0 auto` : la pastille ne se comprime jamais dans une rangée serrée, contrairement au
  libellé qui peut être tronqué.

## Écarts et évolutions

- **Écart assumé.** Le `Badge` d'Ant Design n'a pas la même anatomie : positionnement absolu,
  radius pleine hauteur, palette propre. D'où un composant construit plutôt qu'une enveloppe.
  Conséquence directe : **`Badge` n'est pas réexporté par `src/ui.ts`**. Tant qu'il l'était, un
  écran a rendu la pastille flottante d'AntD sur le bouton Filters au lieu du compteur dans le
  flux. Un besoin, une entrée.
- **À construire.** Le format des grands nombres (« 99+ ») n'est pas décrit dans la maquette.
