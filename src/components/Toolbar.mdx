Barre d'outils d'un tableau. Recherche à gauche, actions à droite, **ordre stable d'un écran à
l'autre**. Elle se pose en haut du panneau qui contient le tableau, jamais ailleurs.

<Canvas of={ToolbarStories.Standard} />

## Props

<Controls of={ToolbarStories.Standard} />

Les booléens de visibilité de la maquette (`Show search`, `Show filter`, `Show edit view`,
`Show export`, `Show primary`) deviennent en code deux emplacements que la page remplit ou non :
`search` et `actions`. Ne pas passer un emplacement revient à mettre son booléen à `false`.

**Le test qui tranche** : si l'action garde du sens quand le tableau est vide, elle est de page.
« New segment » crée une ressource indépendante de tout filtre : sa place est dans l'ActionBar.
« Edit view » configure les colonnes du tableau : sa place est ici, à côté de ce qu'elle modifie.

Sur une liste standard, cela veut dire `Show export` et `Show primary` à **false**.

## Règles d'usage

- **Ordre fixe** : recherche à gauche, puis Filters, puis Edit view. Une action au même endroit
  d'un écran à l'autre s'atteint sans la chercher.
- **Jeu d'icônes normé** : Filters = `filter`, Edit view = `view`, Export = `download`, création =
  `plus`. Pas de substitution.
- **Icônes sur tous les boutons de la rangée, ou sur aucun.** Un mélange donne une rangée bancale.
- La Toolbar se **dose par module** : Experiments n'a pas d'action primaire, Feeds Overview n'a
  qu'une recherche. Un emplacement vide se retire, il ne se remplit pas pour faire symétrique.
- Le champ de recherche est **le seul Input du DS sans label visible** : la loupe et le placeholder
  suffisent à en dire la fonction. Il porte quand même un `aria-label`.

## Anatomie

1. **Rangée** : `space-between`, gap 12, alignée sur la largeur du tableau.

## Écarts et évolutions

- **Écart avec la production.** Les actions de page et les actions de tableau sont mélangées écran
  par écran. La règle de portée est la réponse à l'incohérence remontée par le client ; l'avant /
  après est dans la page Audit du fichier Figma.
- **À construire.** La barre d'actions groupées qui remplace la Toolbar quand des lignes sont
